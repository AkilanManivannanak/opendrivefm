# test imports. nuscenes-devkit in particular is the package that could not be

# depends on a fragile transitive install is a gate that fails for reasons
# unrelated to the code it is meant to guard.
#
# The tests add src/ to sys.path themselves, so the package does not need to be
# installed at all.
#
# torch is installed separately in CI from the CPU index. Do not add it here:
# plain `pip install torch` pulls the CUDA build, which is ~2.5GB and pointless
# on a CPU runner.
